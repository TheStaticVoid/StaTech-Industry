# StaTech Industry 2.0.0rc1 Changelog:
It's been a long road, but here we are!

This update took a lot of effort by both myself ([@GW-Dev](https://github.com/GW-Dev)) and by [@truepurpledino](https://github.com/truepurpledino) (again). The GuideME book has been implemented, the companion mod has been added, and much documentation and cleanup has been done. As for plans after this update, we'll see how many bugs pop up, though we do have a lot of ideas for the next two major content updates. We'll talk about that more after we release any needed hotfixes.

As always, please make sure to file all issues on GitHub. Feedback in regards to progression, recipes, QoL, or anything else is also most welcome, though the Discord server is the best place for that.
