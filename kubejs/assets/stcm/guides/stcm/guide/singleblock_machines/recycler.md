# Recycler

<GameScene zoom="4" interactive={true} fullWidth={true}>
    <Block id="modern_industrialization:recycler" />
</GameScene>

The Recycler is a singleblock electric machine which allows you to reduce items you have an abundance of into scrap, which can be turned into UU-Matter (the item). UU-Matter (still the item) can be used in the Matter Fabricator to generate a number of materials.

The Recycler has a higher chance of producing a scrap the more valuable the input item is.

The Recycler can also be used to turn Artifacts into a special Artifact Dust (you can only recycle the non-craftable ones, nice try), which can be turned into a Mimic Spawn Egg in the Matter Fabricator.
