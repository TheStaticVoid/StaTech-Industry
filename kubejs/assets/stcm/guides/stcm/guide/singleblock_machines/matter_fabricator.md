# Matter Fabricator

<GameScene zoom="4" interactive={true} fullWidth={true}>
    <Block id="modern_industrialization:matter_fabricator" />
</GameScene>

The Matter Fabricator is a singleblock electric machine which allows you to turn UU-Matter (the item) into a number of useful resources! UU-Matter (still the item) can be made by processing Scrap in the Implosion Compressor.

See the Recycler page for more information on Scrap.
